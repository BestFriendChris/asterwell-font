FONTLOG for Asterwell Text
==========================

This file provides detailed information on the Asterwell Text font
family. This information should be distributed along with the Asterwell
Text fonts and any derivative works.


Basic Font Information
----------------------

Asterwell Text is a serif text family for writing and reading, and for
the user interface around the text: a full prose face in roman and
italic, plus a curated set of symbols, markers and ornaments that share
the prose face's colour and keep their form at every weight; in the
italic the stars turn but do not slant.

    Family      Asterwell Text
    Vendor ID   ASTW
    License     SIL Open Font License, Version 1.1 (see OFL.txt)
    Repository  https://github.com/BestFriendChris/asterwell-font

Each release ships two variable fonts (roman and italic, axes
opsz 7-72 and wght 200-900), sixteen static instances derived from
them at opsz 12, and WOFF2 builds of the two variable fonts.

The family is assembled from three sources:

  * Literata 3.103 -- the prose face, unchanged in outline, metrics and
    layout. Literata is by TypeTogether, released under the SIL Open
    Font License, Version 1.1.
    https://github.com/googlefonts/literata

  * DejaVu Sans 2.37 -- selected symbols, arrows, geometric shapes and
    dingbats that Literata does not cover, imported and scaled to
    Literata's cap height.
    https://dejavu-fonts.github.io/
    https://github.com/dejavu-fonts/dejavu-fonts

  * An original six-petal star family drawn for this project, from one
    parametric template: U+273D HEAVY TEARDROP-SPOKED ASTERISK at full
    size, with its siblings U+273B TEARDROP-SPOKED ASTERISK, U+273C
    OPEN CENTRE TEARDROP-SPOKED ASTERISK, U+273E SIX PETALLED BLACK AND
    WHITE FLORETTE and U+2743 HEAVY TEARDROP-SPOKED PINWHEEL ASTERISK
    drawn from the same template as its lighter, open-centred,
    hollow-petalled and pinwheel variants, and U+204E LOW ASTERISK,
    U+2051 TWO ASTERISKS ALIGNED VERTICALLY and U+2042 ASTERISM built
    from one shared small-star outline. U+2042 replaces Literata's own
    asterism so the eight read as one set. In the italic the template
    is turned 30 degrees, so the petals point up-left and up-right
    rather than one straight up, and the stacked stars of U+2051 and
    U+2042 lean with the italic as Literata's own colon and asterism
    do; nothing is sheared. The four- and eight-spoke members of the
    same style (U+2722, U+274A, U+274B) are DejaVu Sans imports for
    now: a different spoke count needs its own optical tuning, which is
    planned, not overlooked.

The SIL Open Font License and its FAQ: https://openfontlicense.org


Sources and Licensing
---------------------

Asterwell Text is a Modified Version of Literata and is released, in
whole, under the SIL Open Font License, Version 1.1. OFL.txt carries
this project's copyright line above Literata's, as OFL condition 2 and
OFL FAQ 3.1 require; the license body is the canonical OFL 1.1 text,
copied byte for byte from the pinned Literata OFL.txt and never
modified.

Literata declares no Reserved Font Name, so none is inherited. This
project reserves the single word "Asterwell" (OFL FAQ 5.5: reserve the
unique word, not the generic one). Anyone modifying these fonts must
therefore rename them.

The symbols imported from DejaVu Sans 2.37 are drawn from material the
DejaVu project placed in the public domain ("DejaVu changes are in
public domain", DEJAVU-LICENSE.txt). The Bitstream Vera and Arev
copyright, trademark and permission notices from that file are
reproduced verbatim in DEJAVU-LICENSE.txt, distributed with these
fonts, and in the fonts' own name table, as the DejaVu license
requires.

The build verifies that no code point present in Bitstream Vera Sans
1.10 is imported from DejaVu. The two sets share seven code points
(U+00D7, U+2022, U+2212, U+2248, U+2264, U+2265, U+25CA); every one of
them is taken from Literata instead, and the check fails the build if
that ever stops being true. The fixture it checks against is
qa/vera-1.10-codepoints.txt.

The family name "Asterwell Text" contains none of the words
"Bitstream", "Vera", "Arev", "Tavmjong Bah" or "DejaVu", so the rename
conditions in the DejaVu license are satisfied by construction.

DejaVuMathTeXGyre.ttf was not used as a source, and no glyph in this
family derives from it; the AMSFonts clause in DEJAVU-LICENSE.txt
therefore applies to no shipped glyph. The file is reproduced whole
because it is the DejaVu license as published.

These fonts may not be sold by themselves. OFL condition 1 and the
Bitstream Vera permission notice agree on this: the font software may
be bundled and sold as part of a larger package, but no copy of the
font software on its own may be sold.


Glyph Provenance
----------------

Every code point the family promises is listed, one per row, in
sources/allowlist.tsv, together with the source of its outline:

    custom     an original Asterwell outline
    literata   preserved from Literata; neither imported nor redrawn
    dejavu     imported from DejaVu Sans, scaled to Literata's cap
               height (uniform scale 700/1493, Literata's cap height
               over DejaVu's), except where the row's note column
               records a per-code-point override

As of this writing that file has 532 rows: 8 custom, 24 literata and
500 dejavu. The file is generated from the pinned upstream fonts and
checked in, so changing an upstream pin or an allowlist rule produces a
reviewable coverage diff rather than a silent change in what the family
covers.

Twenty-one rows are flagged emoji_presentation. Those code points have
a default emoji presentation on emoji-capable platforms; append
U+FE0E (VARIATION SELECTOR-15) after such a character in text to get
the typographic form from this family rather than a colour emoji from
the platform's emoji font.

to main is the release: the entry reads "M.mmm (YYYY-MM-DD): what
changed." at the start of a line, the minor is exactly three digits
